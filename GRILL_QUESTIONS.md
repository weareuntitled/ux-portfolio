# Grill Workflow

## How It Works

1. **Load the skill** — Run `/grill-me` to load this workflow
2. **Read questions** — I read `GRILL_QUESTIONS.md` automatically
3. **You answer** — Tell me your answers (e.g., "Q1:A, Q2:B, Q3:A...")
4. **We iterate** — I ask follow-up questions based on your answers
5. **Reach consensus** — We keep going until we align on everything

## Rules

- Always read `GRILL_QUESTIONS.md` first when loading this skill
- One question at a time
- Translate technical stuff into human language
- Use interactive questions (multiple choice, no free text)
- Only outcome questions, not technical stuff
